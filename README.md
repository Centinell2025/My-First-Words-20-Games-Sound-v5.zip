# My First Words — 20 Games with Sound

Mobile-friendly bilingual early language play for ages 1–3, accompanied by an adult.

## Features
- 20 activities and 80 picture-word prompts
- English and Spanish text-to-speech using device voices
- Tap feedback sounds, mute switch, large touch targets
- Parent guidance tailored to age
- No microphone, accounts, ads, tracking, or collection of children's information

## Running
Open `index.html` in a browser, or enable GitHub Pages to host the site. On mobile, tap **Test sound** to enable audio. Speech synthesis varies by operating system and browser.

This is a prototype, not a substitute for caregiver interaction or a speech-language professional. Especially for children under two, prioritize face-to-face interaction over screens.
