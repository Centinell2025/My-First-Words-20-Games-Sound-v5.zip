# 🧸 My First Words — 20 Games With Sound

A mobile-friendly early-language **prototype** for children ages 1–3, designed for boys and girls with parent/caregiver participation. The app defaults to English and can switch to Spanish.

## Features

- 20 interactive topics with 80 picture-word prompts
- Spoken words with selectable English/Spanish device voices and adjustable speed
- Large touch-friendly choices and clearly visible feedback: **green ✓** for a correct answer; **soft red ✕** for a wrong selection; the right picture also turns green for guidance
- Gentle praise rather than punishment, plus a next-question button
- Parent-guided activities, age-group tips, sound test and mute control
- Session progress indicator; no account, advertisements, microphone, tracking or upload of children's data
- Installable web-app files (PWA); not a native App Store or Play Store release

## Open and test

1. Open the deployed site in Chrome (Android) or Safari (iPhone), or open `index.html` locally on a computer.
2. Turn up the phone's media volume, disable silent mode if necessary, and tap **Test sound**.
3. Select the language (EN or ES); under the parent's settings select **Clear**, **Slow**, or **Normal** speech, and test any available voice.
4. Pick a game such as **Animals**. Tap a correct picture: it turns green ✓. Tap another picture: it becomes soft red ✕ and the correct one turns green ✓.
5. Use **Listen again** and **Next →**. The audio is generated by voices installed in the browser/operating system, so sound quality and availability vary.

## Publish on GitHub Pages

In repository **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**. Check the **Actions** tab for the workflow **Publish My First Words** and its deployment status. Do not assume publication succeeded until GitHub reports a successful deployment.

## Parent / safety notes

This prototype is a supplement to real-world language interaction, not a speech-therapy or diagnostic tool. Prioritize face-to-face talking, reading, singing and play, particularly for children under two. For toddlers who use it, make sessions brief and shared with an adult.
